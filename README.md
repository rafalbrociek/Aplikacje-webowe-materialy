# Aplikacje webowe i sieciowe

Materiały laboratoryjne do przedmiotu
Aplikacje webowe i sieciowe.

## Technologie

### Backend
- C#
- ASP.NET Core Web API
- Clean Architecture
- MediatR
- Entity Framework Core

### Frontend
- React
- TypeScript
- Vite
- React Router

## Struktura

- backend/ - rozwijany projekt Web API
- frontend/ - niezależne przykłady React
- docs/ - dokumentacja

## Wersje backendu

| Wersja | Opis |
|---|---|
| backend-v1.0 | Podstawowe Web API |
| backend-v2.0 | MediatR + FluentValidation |


## Przykłady React

| Wersja | Opis |
|---|---|
| 1 | Tworzenie komponentu i przekazywanie właściowści |
| 2 | Drzewo komponentów, props i callback |
| 3 | Komunikacja z jsonserver przez użycie fetch |
| 4 | Nawigacja po aplikacji przy użyciu react-router |
| 5 | Aplikacja waluty (przykład łączenia przy użyciu Axios i magazyn stanu Zustand) |
