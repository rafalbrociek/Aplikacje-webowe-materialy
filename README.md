# Aplikacje webowe i sieciowe

Materiały laboratoryjne do przedmiotu
Aplikacje webowe i sieciowe.

## Technologie

### Backend
- C#
- ASP.NET Core Web API
- Clean Architecture
- MediatR
- Entity Framework Core

### Frontend
- React
- TypeScript
- Vite
- React Router

## Struktura

- backend/ - rozwijany projekt Web API
- frontend/ - niezależne przykłady React
- docs/ - dokumentacja

## Wersje backendu

| Wersja | Opis |
|---|---|
| backend-v1.0 | Podstawowe Web API |
| backend-v2.0 | MediatR + FluentValidation |
